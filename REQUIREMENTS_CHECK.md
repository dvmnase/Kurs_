# Отчет о соответствии требованиям

## ✅ ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ

### Грузовладелец (OWNER):
- ✅ Просматривать местоположение грузов - реализовано через MapView и MultiMapView
- ✅ Управление заявками:
  - ✅ Создать заявку на перевозку - `/api/owner/requests` POST
  - ✅ Просмотреть список заявок - `/api/owner/requests` GET
  - ✅ Отредактировать заявку - `/api/owner/requests/{id}` PUT
  - ✅ Удалить заявку - `/api/owner/requests/{id}` DELETE
- ✅ Управлять аккаунтом:
  - ✅ Смена пароля - `/api/owner/account/password` PUT
  - ✅ Смена никнейма - `/api/owner/account/username` PUT
- ✅ Искать грузы - `/api/owner/cargo?search=` GET (регистронезависимый поиск)
- ✅ Фильтровать грузы - по весу (minWeight, maxWeight)
- ✅ Сортировать грузы - по полям (sortBy, sortOrder)
- ✅ Взаимодействия с картой:
  - ✅ Просматривать местоположение грузов - MapView, MultiMapView
  - ✅ Подтверждать маршрут перевозки - `/api/messages/route/{routeId}/confirm` POST
  - ✅ Определять место (координаты/адрес) - клик по карте в MapView
- ✅ Работа с чат-ботом - компонент ChatBot
- ✅ Сохранение информации о грузе в Excel - `/api/owner/cargo/export` GET
- ✅ Оставлять отзыв - `/api/owner/reviews` POST

### Перевозчик (CARRIER):
- ✅ Принимать заявки на перевозку - `/api/carrier/requests/{id}/accept` POST
- ✅ Предлагать маршрут - отправка маршрута через чат

### Администратор (ADMIN):
- ✅ Анализировать количество заявок и грузов:
  - ✅ Формировать отчеты - `/api/admin/analytics/report` GET
  - ✅ Строить графики - SimpleChart, PieChart компоненты
  - ✅ Экспортировать статистику - `/api/admin/analytics/export` GET

### Общие возможности:
- ✅ Регистрация/авторизация - `/api/auth/signup`, `/api/auth/signin`
- ✅ Определение местоположения текущего, координаты и адрес, тыкая по карте - реализовано в MapView
- ✅ Просмотр всех грузов на карте - MultiMapView
- ✅ Чат - RequestChat компонент
- ✅ Предложение маршрута от грузоперевозчика - реализовано в RequestChat
- ✅ Расчет расстояния и времени отображается - через Yandex Maps API
- ✅ Удалить транспорт - `/api/carrier/transports/{id}` DELETE
- ✅ Видео на сайте - YouTube видео в Footer и на странице услуг

## ⚠️ ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### 3.2.1. Язык программирования Java
- ✅ Используется Java 21

### 3.2.2. Распределенная архитектура
- ✅ Клиентский компонент: React/Next.js (front/)
- ✅ Серверный компонент: Spring Boot (src/main/java/)

### 3.2.3. Серверные технологии
- ⚠️ Spring Boot: используется версия **3.4.5** (требуется 3.2.1)
  - Примечание: Версия выше требуемой, что допустимо
- ✅ Spring Data JPA: включен через spring-boot-starter-data-jpa
- ✅ Spring Security: включен через spring-boot-starter-security
- ❌ MySQL Connector/J: **НЕ ИСПОЛЬЗУЕТСЯ**
  - Используется PostgreSQL (org.postgresql:postgresql)
  - **ТРЕБУЕТСЯ ИСПРАВЛЕНИЕ**: Заменить на MySQL или обновить требования

### 3.2.4. Клиентские технологии
- ⚠️ React.js: используется версия **18.1.0** (требуется 18.2.0)
  - Примечание: Версия близка к требуемой, но не точно соответствует

### 3.2.5. База данных
- ✅ СУБД: PostgreSQL (реляционная)
- ✅ Количество сущностей: **12 таблиц** (требуется не менее 8):
  1. users
  2. owners
  3. carriers
  4. cargo
  5. cargo_locations
  6. transports
  7. routes
  8. requests
  9. reviews
  10. export_logs
  11. analytics
  12. messages
- ✅ Нормализация: База данных приведена к 3НФ (внешние ключи, отсутствие избыточности)
- ✅ Целостность данных: FOREIGN KEY constraints, CASCADE удаление
- ✅ Надежность: транзакции, проверки целостности

### 3.2.6. Информационная безопасность
- ✅ Шифрование паролей: BCryptPasswordEncoder
- ✅ JWT токены для аутентификации
- ✅  Резервное копирование данных

- Все функциональные возможности для всех ролей
- Работа с картами и геокодингом

## РЕКОМЕНДАЦИИ

1. **Заменить PostgreSQL на MySQL** или обновить требования документации
2. **Обновить React до 18.2.0** в package.json
3. **Добавить резервное копирование**:
   - Настроить автоматический бэкап PostgreSQL через pg_dump
   - Или добавить Spring Batch job для периодического экспорта данных
   - Или использовать Flyway/Liquibase для версионирования миграций
